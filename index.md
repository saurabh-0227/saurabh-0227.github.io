## 🔧 Troubleshooting

**The download will not start.**
Refresh the releases page and click the Windows file again. Make sure your browser is not blocking downloads — look for a small warning icon in the address bar.

**Windows shows a blue warning box.**
Click "More info," then "Run anyway." This is normal for downloaded software.

**AutoCua opens but does not click anything.**
Make sure the app window is active and that you have typed a task into the instruction box. Some computers also need permission for the app to control the mouse and keyboard — Windows will ask, and you should click "Yes."

**The mouse moves to the wrong place.**
If you have more than one monitor, keep the target window on your main screen while AutoCua works.

**A task stops partway through.**
Some tasks need you to be logged in to a website or to have a file open already. Set that up first, then ask AutoCua to continue.

**Everything is slow.**
Close other programs you are not using. AutoCua needs screen space and processing power to see and act.
